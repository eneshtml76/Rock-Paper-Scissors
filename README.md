# 🎮 Rock Paper Scissors

My 11th web project.

I created this Rock Paper Scissors game with HTML, CSS and JavaScript.

## Features

- 🪨 Rock, Paper, Scissors choices
- 🤖 Random computer moves
- 🎯 5 round game system
- 🏆 Score tracking
- 🔄 Restart button
- ✨ Modern UI design

## Technologies

- HTML5
- CSS3
- JavaScript

## How to Play

Choose your move and try to beat the computer.

Rock beats Scissors  
Paper beats Rock  
Scissors beats Paper

The player with the highest score after 5 rounds wins.
